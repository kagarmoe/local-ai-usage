# local-ai-usage collector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A swamp repo that snapshots Claude Code and Codex token use per ISO week from local logs, writes a redacted `public/summary.json`, and commits it, triggered by launchd at login and daily.

**Architecture:** Two scanner models parse local JSONL logs into normalized `Call`s, aggregate them per week, and write one versioned `weekly` resource per week. A `summary` model reads all stored weeks and writes the public JSON. A workflow report shows the private markdown. A `command/shell` step commits the JSON. Pure logic lives in `extensions/models/_lib/` and is unit-tested. The model files only wire it to swamp.

**Tech Stack:** swamp 20261009.202715.0, TypeScript on Deno 2.9.7 (bundled with swamp at `~/.swamp/deno/deno`), `npm:zod@4`, `jsr:@std/yaml@1.3.0`, `jsr:@std/assert@1.0.19`, launchd, git, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-local-ai-usage-design.md`

## Global Constraints

- Work on `main` in `~/repos/local-ai-usage`. The repo is local-only until Task 11, and swamp data (`.swamp/`) lives in this checkout. Never `git reset --hard`. End every commit message with the session attribution trailers.
- Deno: `DENO=~/.swamp/deno/deno`. Run tests with `$DENO task test` and type checks with `$DENO task check`.
- Imports: `npm:zod@4`, `jsr:@std/yaml@1.3.0`, `jsr:@std/assert@1.0.19`. Static imports only. Never bare `"zod"`.
- Model types: `@kagarmoe/local-ai-usage/claude-code`, `@kagarmoe/local-ai-usage/codex`, `@kagarmoe/local-ai-usage/summary`, all at version `2026.10.09.1`. Report: `@kagarmoe/local-ai-usage-report`.
- Instance names: `claude-code`, `codex`, `summary`, `publish`. Workflow: `local-ai-usage-weekly`.
- Weekly resource: spec `weekly`, instance name `weekly-<ISO week>` (e.g. `weekly-2026-W41`).
- Weeks are ISO weeks in the local time zone. Tests run with `TZ=America/Los_Angeles`.
- "Input" = input + cache read + cache write. "Long session" = more than 50 calls. Codex `input_tokens` includes cached tokens. Reasoning is part of output and is never added to it.
- The public JSON contains no project names, paths, session IDs, git branches, prompts, or tool names.
- The collector uses no LLM tokens.
- Tests: lean, automatic in CI, real assertions. No test harness package; the one wiring test uses a 10-line fake context.

### Spec deviations (decided while planning; flagged for review)

1. **The public JSON is built by a `summary` model method, not the report.** A workflow-scope report runs after the run finishes, so the publish step could not read it. The report still renders the private markdown.
2. **No standalone `calibrate()` method.** Each scan prices Claude models that have no rate yet, from `cost-state` records, before it costs the week. Existing rates never change automatically, so `prices.yaml` stays stable.
3. **`costCheck` compares priced `cost-state` token counts with `cost-state` cost, per model.** Transcripts miss background calls (for example, Haiku title generation) that `totalCostUSD` includes, so comparing transcript tokens with `totalCostUSD` would report false drift.
4. **The workflow calls `scanMissing` (no arguments) instead of a forEach over `scan(week)`.** `scan(week)` stays for manual re-scans.
5. `weeks[]` is sorted newest first. `rateLimits` peaks and `baseline.codex` are `null` when there is no data.

## Review Focus

1. **A session that crosses Sunday midnight.** Each call lands in the week of its own timestamp, and the session counts in both weeks. Test: Task 7, `buildSnapshots` week-boundary test.
2. **The DST fall-back week (2026-W44, US clocks go back on 2026-11-01).** The week is 7 local days and 169 hours, and both 01:30 calls fall in Sunday hour 1. Tests: Task 2 `weekBounds` DST test, Task 3 `aggregateWeek` DST test.
3. **The current, unfinished week.** It is never snapshotted; otherwise a partial week would be frozen as complete. Tests: Task 2 `completedWeeks` test, Task 7 wiring test.
4. **A new model with no rate.** That model's cost is `null`, totals sum the priced calls only, and the markdown names the unpriced model. Claude models get a rate on the next scan. Tests: Task 3 cost test, Task 6 calibrate test, Task 8 markdown test.
5. **A daily re-run with nothing new.** It writes no snapshots and produces a byte-identical `summary.json`, so publish makes no commit. Tests: Task 7 re-run assertion, Task 8 determinism test, Task 9 manual check.

```ts
// ISO weeks in the local time zone. Day steps use setDate, so DST days stay whole days.

const WEEK_MS = 7 * 86_400_000;

/** Local midnight of the Monday that starts d's ISO week. */
export function weekStart(d: Date): Date {
  const s = new Date(d.getFullYear(), d.getMonth(), d.getDate());
  s.setDate(s.getDate() - ((s.getDay() + 6) % 7));
  return s;
}

/** ISO week label, e.g. "2026-W41". The week belongs to the year of its Thursday. */
export function isoWeek(d: Date): string {
  const monday = weekStart(d);
  const thursday = new Date(monday);
  thursday.setDate(thursday.getDate() + 3);
  const year = thursday.getFullYear();
  const week1 = weekStart(new Date(year, 0, 4));
  const n = Math.round((monday.getTime() - week1.getTime()) / WEEK_MS) + 1;
  return `${year}-W${String(n).padStart(2, "0")}`;
}

/** Local start (inclusive) and end (exclusive) of an ISO week label. */
export function weekBounds(week: string): { start: Date; end: Date } {
  const m = /^(\d{4})-W(\d{2})$/.exec(week);
  if (!m) throw new Error(`Bad ISO week: ${week}`);
  const start = weekStart(new Date(Number(m[1]), 0, 4));
  start.setDate(start.getDate() + (Number(m[2]) - 1) * 7);
  const end = new Date(start);
  end.setDate(end.getDate() + 7);
  return { start, end };
}

/** Weeks from the one holding `oldest` up to, not including, the current week. */
export function completedWeeks(oldest: Date, now: Date): string[] {
  const out: string[] = [];
  const current = weekStart(now).getTime();
  for (const d = weekStart(oldest); d.getTime() < current; d.setDate(d.getDate() + 7)) out.push(isoWeek(d));
  return out;
}

/** Local calendar date, YYYY-MM-DD. */
export function localDate(d: Date): string {
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}-${String(d.getDate()).padStart(2, "0")}`;
}

/** ISO day of week: 1 = Monday … 7 = Sunday. */
export const isoDow = (d: Date): number => ((d.getDay() + 6) % 7) + 1;
```

```ts
import { isoDow, localDate } from "./week.ts";

/** One model call, normalized across tools. `project` is private: it stays in the snapshot's `private` block. */
export type Call = {
  ts: Date;
  session: string; // main session id, or the subagent's file path
  main: boolean; // false for subagent calls
  model: string;
  project: string;
  input: number; // uncached input
  cacheRead: number;
  cacheWrite: number;
  output: number;
  reasoning: number; // part of output (Codex only); never added to it
  costUSD: number | null;
};

export type ModelStat = { calls: number; input: number; output: number; costUSD: number | null };
export type Tokens = { input: number; cacheRead: number; cacheWrite: number; output: number; reasoning?: number };
type Mixes = { models: Record<string, ModelStat>; subagentModels: Record<string, ModelStat> };
export type DayStat = { date: string; sessions: number; calls: number; tokens: Tokens; costUSD: number | null } & Mixes;
export type HourStat = { dow: number; hour: number; input: number; output: number; costUSD: number | null } & Mixes;
export type ToolWeek = {
  sessions: number;
  calls: number;
  tokens: Tokens;
  costUSD: number | null;
  perDay: DayStat[];
  perHour: HourStat[];
  context: { avgLongSession: number; p95: number; peak: number };
  sessionStartMedian: number;
} & Mixes;

export const LONG_SESSION_CALLS = 50;

/** Prompt-side tokens of a call: the spec's "input". */
export const context = (c: Call): number => c.input + c.cacheRead + c.cacheWrite;

/** Sum of priced calls; null only when nothing is priced. */
const addCost = (a: number | null, b: number | null) => (b === null ? a : (a ?? 0) + b);

function mix(calls: Call[]): Mixes {
  const m: Mixes = { models: {}, subagentModels: {} };
  for (const c of calls) {
    const s = ((c.main ? m.models : m.subagentModels)[c.model] ??= { calls: 0, input: 0, output: 0, costUSD: null });
    s.calls++;
    s.input += context(c);
    s.output += c.output;
    s.costUSD = addCost(s.costUSD, c.costUSD);
  }
  return m;
}

function totals(calls: Call[], withReasoning: boolean): { tokens: Tokens; costUSD: number | null } {
  const tokens: Tokens = { input: 0, cacheRead: 0, cacheWrite: 0, output: 0 };
  if (withReasoning) tokens.reasoning = 0;
  let costUSD: number | null = null;
  for (const c of calls) {
    tokens.input += c.input;
    tokens.cacheRead += c.cacheRead;
    tokens.cacheWrite += c.cacheWrite;
    tokens.output += c.output;
    if (withReasoning) tokens.reasoning = (tokens.reasoning ?? 0) + c.reasoning;
    costUSD = addCost(costUSD, c.costUSD);
  }
  return { tokens, costUSD };
}

const sessionCount = (calls: Call[]) => new Set(calls.filter((c) => c.main).map((c) => c.session)).size;

function groupBy(calls: Call[], key: (c: Call) => string): Map<string, Call[]> {
  const m = new Map<string, Call[]>();
  for (const c of calls) {
    const k = key(c);
    if (!m.has(k)) m.set(k, []);
    m.get(k)!.push(c);
  }
  return m;
}

/** Aggregate one week's calls. `start` is the week's local Monday. Returns null for no calls ("no data", not zeros). */
export function aggregateWeek(calls: Call[], start: Date, withReasoning: boolean): ToolWeek | null {
  if (calls.length === 0) return null;
  const sorted = [...calls].sort((a, b) => a.ts.getTime() - b.ts.getTime());

  const perDay: DayStat[] = [];
  for (let i = 0; i < 7; i++) {
    const d = new Date(start);
    d.setDate(d.getDate() + i);
    const date = localDate(d);
    const day = sorted.filter((c) => localDate(c.ts) === date);
    perDay.push({ date, sessions: sessionCount(day), calls: day.length, ...totals(day, withReasoning), ...mix(day) });
  }

  // Sparse: only hours with calls.
  const perHour: HourStat[] = [...groupBy(sorted, (c) => `${isoDow(c.ts)}-${c.ts.getHours()}`)]
    .map(([k, hc]) => {
      const [dow, hour] = k.split("-").map(Number);
      const t = totals(hc, false);
      return { dow, hour, input: hc.reduce((n, c) => n + context(c), 0), output: t.tokens.output, costUSD: t.costUSD, ...mix(hc) };
    })
    .sort((a, b) => a.dow - b.dow || a.hour - b.hour);

  const sessions = [...groupBy(sorted, (c) => c.session).values()];
  const long = sessions.filter((s) => s.length > LONG_SESSION_CALLS).flat();
  const ctx = sorted.map(context).sort((a, b) => a - b);
  const starts = sessions.filter((s) => s[0].main).map((s) => context(s[0])).sort((a, b) => a - b);

  return {
    sessions: sessionCount(sorted),
    calls: sorted.length,
    ...totals(sorted, withReasoning),
    perDay,
    perHour,
    ...mix(sorted),
    context: {
      avgLongSession: long.length ? Math.round(long.reduce((n, c) => n + context(c), 0) / long.length) : 0,
      p95: ctx[Math.ceil(0.95 * ctx.length) - 1],
      peak: ctx[ctx.length - 1],
    },
    sessionStartMedian: starts.length ? starts[Math.floor((starts.length - 1) / 2)] : 0, // lower median
  };
}
```

```ts
import { parse, stringify } from "jsr:@std/yaml@1.3.0";

/** USD per million tokens. */
export type Rate = { input: number; cacheRead: number; cacheWrite: number; output: number };
export type Prices = { claude: Record<string, Rate>; codex: Record<string, Rate> };

const HEADER = "# USD per million tokens. claude: scans add missing models from cost-state records. codex: enter by hand.\n";

export function loadPrices(path: string): Prices {
  const p = (parse(Deno.readTextFileSync(path)) ?? {}) as Partial<Prices>;
  return { claude: p.claude ?? {}, codex: p.codex ?? {} };
}

export function savePrices(path: string, p: Prices): void {
  Deno.writeTextFileSync(path, HEADER + stringify(p, { sortKeys: true }));
}

/** Cost of one call, or null when the model has no rate. Reasoning is inside output, so it is not priced again. */
export function priceCall(
  rates: Record<string, Rate>,
  c: { model: string; input: number; cacheRead: number; cacheWrite: number; output: number },
): number | null {
  const r = rates[c.model];
  return r ? (c.input * r.input + c.cacheRead * r.cacheRead + c.cacheWrite * r.cacheWrite + c.output * r.output) / 1e6 : null;
}
```

```ts
export type Row = Record<string, any>;

/** Every *.jsonl file under dir, recursively. Throws if dir is missing. */
export function listJsonl(dir: string): string[] {
  const out: string[] = [];
  for (const e of Deno.readDirSync(dir)) {
    const p = `${dir}/${e.name}`;
    if (e.isDirectory) out.push(...listJsonl(p));
    else if (e.isFile && e.name.endsWith(".jsonl")) out.push(p);
  }
  return out;
}

/** Parsed rows of a JSONL file. Bad lines, including a half-written last line, are counted, not thrown. */
export function readJsonl(path: string): { rows: Row[]; skipped: number } {
  const rows: Row[] = [];
  let skipped = 0;
  for (const line of Deno.readTextFileSync(path).split("\n")) {
    if (!line.trim()) continue;
    try {
      rows.push(JSON.parse(line));
    } catch {
      skipped++;
    }
  }
  return { rows, skipped };
}
```

```ts
import type { Call } from "./aggregate.ts";
import { readJsonl } from "./jsonl.ts";

export type CostState = {
  sessionId: string;
  startTime: number; // epoch ms
  totalCostUSD: number;
  modelUsage: Record<string, {
    inputTokens: number;
    outputTokens: number;
    cacheReadInputTokens: number;
    cacheCreationInputTokens: number;
    costUSD: number;
  }>;
};

/** Parse Claude Code transcripts under `root` (the projects dir). The first path segment names the project (private). */
export function parseClaude(files: string[], root: string): { calls: Call[]; costStates: CostState[]; skipped: number } {
  const byId = new Map<string, Call>();
  const costs = new Map<string, CostState>();
  let skipped = 0;
  for (const f of files) {
    const { rows, skipped: s } = readJsonl(f);
    skipped += s;
    const project = f.slice(root.length + 1).split("/")[0];
    const subFile = f.includes("/subagents/");
    for (const r of rows) {
      if (r.type === "cost-state" && r.sessionId) {
        costs.set(r.sessionId, r as CostState); // cumulative: the last record per session wins
        continue;
      }
      const m = r.message;
      if (r.type !== "assistant" || !m?.id || !m.usage || m.model === "<synthetic>") continue;
      const main = !(subFile || r.isSidechain);
      // Streaming writes one line per content block with the same id; the last line wins.
      byId.set(m.id, {
        ts: new Date(r.timestamp),
        session: main ? r.sessionId : f,
        main,
        model: m.model,
        project,
        input: m.usage.input_tokens ?? 0,
        cacheRead: m.usage.cache_read_input_tokens ?? 0,
        cacheWrite: m.usage.cache_creation_input_tokens ?? 0,
        output: m.usage.output_tokens ?? 0,
        reasoning: 0,
        costUSD: null,
      });
    }
  }
  return { calls: [...byId.values()], costStates: [...costs.values()], skipped };
}
```

```ts
import type { Call } from "./aggregate.ts";
import { readJsonl, type Row } from "./jsonl.ts";

export type RateSample = { ts: Date; fiveHour: number | null; weekly: number | null };

/** Parse Codex session logs. Each file is one session; `session_meta.source.subagent` marks subagent sessions. */
export function parseCodex(files: string[]): { calls: Call[]; rates: RateSample[]; skipped: number } {
  const calls: Call[] = [];
  const rates: RateSample[] = [];
  const seen = new Set<string>();
  let skipped = 0;
  for (const f of files) {
    const { rows, skipped: s } = readJsonl(f);
    skipped += s;
    // Newer logs write token_usage_record per response; then token_count usage would double count.
    const useRecords = rows.some((r) => r.type === "token_usage_record");
    let main = true, project = "", model = "unknown", lastTotal = "";
    for (const r of rows) {
      const p = r.payload ?? {};
      if (r.type === "session_meta") {
        main = !(p.source && typeof p.source === "object" && "subagent" in p.source);
        project = String(p.cwd ?? "").split("/").pop() ?? "";
        continue;
      }
      if (r.type === "turn_context") {
        model = p.model ?? model;
        continue;
      }
      let u: Row | undefined;
      if (r.type === "token_usage_record") {
        if (seen.has(p.response_id)) continue;
        seen.add(p.response_id);
        u = p.usage;
      } else if (r.type === "event_msg" && p.type === "token_count") {
        if (p.rate_limits) {
          rates.push({
            ts: new Date(r.timestamp),
            fiveHour: p.rate_limits.primary?.used_percent ?? null,
            weekly: p.rate_limits.secondary?.used_percent ?? null,
          });
        }
        if (useRecords || !p.info) continue;
        const total = JSON.stringify(p.info.total_token_usage);
        if (total === lastTotal) continue; // repeated event: no new call
        lastTotal = total;
        u = p.info.last_token_usage;
      }
      if (!u) continue;
      const cached = u.cached_input_tokens ?? 0;
      calls.push({
        ts: new Date(r.timestamp),
        session: f,
        main,
        model,
        project,
        input: Math.max(0, (u.input_tokens ?? 0) - cached), // input_tokens includes cached tokens
        cacheRead: cached,
        cacheWrite: u.cache_write_input_tokens ?? 0,
        output: u.output_tokens ?? 0,
        reasoning: u.reasoning_output_tokens ?? 0,
        costUSD: null,
      });
    }
  }
  return { calls, rates, skipped };
}
```

```ts
import type { CostState } from "./claude.ts";
import { priceCall, type Rate } from "./prices.ts";

// shortcut: Anthropic list prices keep fixed ratios to the input rate (cache read 0.1×, 5-minute cache write 1.25×,
// output 5×), so one number per model is fitted. Fit all four rates if costCheck drifts past 2%.
const RATIO = { cacheRead: 0.1, cacheWrite: 1.25, output: 5 };
const round4 = (n: number) => Math.round(n * 1e4) / 1e4;

/** Add a fitted rate for each model in `costStates` that has no rate. Existing rates are kept unchanged. */
export function calibrate(costStates: CostState[], existing: Record<string, Rate>): Record<string, Rate> {
  const sums = new Map<string, { cost: number; units: number }>();
  for (const cs of costStates) {
    for (const [model, u] of Object.entries(cs.modelUsage ?? {})) {
      if (existing[model]) continue;
      const s = sums.get(model) ?? { cost: 0, units: 0 };
      s.cost += u.costUSD;
      s.units += u.inputTokens + RATIO.cacheRead * u.cacheReadInputTokens +
        RATIO.cacheWrite * u.cacheCreationInputTokens + RATIO.output * u.outputTokens;
      sums.set(model, s);
    }
  }
  const out = { ...existing };
  for (const [model, s] of sums) {
    if (!s.units) continue;
    const input = round4((s.cost / s.units) * 1e6);
    out[model] = {
      input,
      cacheRead: round4(input * RATIO.cacheRead),
      cacheWrite: round4(input * RATIO.cacheWrite),
      output: round4(input * RATIO.output),
    };
  }
  return out;
}

/** Price-table check: priced cost-state tokens vs Claude Code's own cost, over fully priced sessions. */
export function costCheck(costStates: CostState[], rates: Record<string, Rate>): { sessions: number; deltaPct: number } {
  let estimate = 0, actual = 0, sessions = 0;
  for (const cs of costStates) {
    const usage = Object.entries(cs.modelUsage ?? {});
    if (!usage.length || usage.some(([m]) => !rates[m])) continue;
    for (const [model, u] of usage) {
      estimate += priceCall(rates, {
        model, input: u.inputTokens, cacheRead: u.cacheReadInputTokens, cacheWrite: u.cacheCreationInputTokens, output: u.outputTokens,
      })!;
      actual += u.costUSD;
    }
    sessions++;
  }
  return { sessions, deltaPct: actual ? Math.round(((estimate - actual) / actual) * 1000) / 10 : 0 };
}
```

```ts
    skippedLines: number;

  definition: { name: string };
  repoDir: string;
  logger: { info: (msg: string, props?: Record<string, unknown>) => void };
  queryData: (predicate: string, select?: string) => Promise<unknown[]>;
  writeResource: (spec: string, name: string, data: unknown) => Promise<unknown>;

type LogFile = { path: string; born: Date; modified: Date };

export const expandHome = (p: string) => p.replace(/^~(?=\/|$)/, Deno.env.get("HOME") ?? "~");

/** Log files with the time of their oldest possible data (birth) and last write. */
export function logFiles(dir: string): LogFile[] {
  return listJsonl(dir).map((path) => {
    const s = Deno.statSync(path);
    const modified = s.mtime ?? new Date();
    const born = s.birthtime && s.birthtime < modified ? s.birthtime : modified;
    return { path, born, modified };
  });
}

function privateDetail(calls: Call[], skippedLines: number): WeeklySnapshot["private"] {
  const projects: Record<string, ModelStat> = {};
  const subagentModelsByProject: Record<string, Record<string, number>> = {};
  const unpriced = new Set<string>();
  for (const c of calls) {
    const p = (projects[c.project] ??= { calls: 0, input: 0, output: 0, costUSD: null });
    p.calls++;
    p.input += context(c);
    p.output += c.output;
    if (c.costUSD === null) unpriced.add(c.model);
    else p.costUSD = (p.costUSD ?? 0) + c.costUSD;
    if (!c.main) {
      const s = (subagentModelsByProject[c.project] ??= {});
      s[c.model] = (s[c.model] ?? 0) + 1;
    }
  }
  return { skippedLines, unpricedModels: [...unpriced].sort(), projects, subagentModelsByProject };
}

/** One snapshot per week from priced calls. Calls outside `weeks` are ignored. */
export function buildSnapshots(o: {
  tool: Tool;
  weeks: string[];
  calls: Call[];
  oldest: Date;
  now: Date;
  skipped: number;
  extras?: (week: string, start: Date, end: Date) => Partial<Pick<WeeklySnapshot, "costCheck" | "rateLimits">>;
}): WeeklySnapshot[] {
  const byWeek = new Map<string, Call[]>(o.weeks.map((w) => [w, []]));
  for (const c of o.calls) byWeek.get(isoWeek(c.ts))?.push(c);
  return o.weeks.map((week) => {
    const { start, end } = weekBounds(week);
    const calls = byWeek.get(week)!;
    return {
      tool: o.tool,
      week,
      start: localDate(start),
      complete: start.getTime() >= o.oldest.getTime(),
      scannedAt: o.now.toISOString(),
      summary: aggregateWeek(calls, start, o.tool === "codex"),
      ...o.extras?.(week, start, end),
      private: privateDetail(calls, o.skipped),
    };
  });
}

/** Weeks that already have a snapshot for this model. */
export async function storedWeeks(ctx: Ctx): Promise<Set<string>> {
  const names = await ctx.queryData(`modelName == "${ctx.definition.name}" && specName == "weekly"`, "name");
  return new Set(names.map((n) => String(n).replace(/^weekly-/, "")));
}

/** Shared scan: pick weeks, parse only files written since the earliest one, write a `weekly` resource per week. */
export async function scanFlow(
  ctx: Ctx,
  dir: string,
  pickWeeks: (oldest: Date, now: Date) => string[],
  build: (files: string[], weeks: string[], oldest: Date, now: Date) => WeeklySnapshot[],
) {
  const abs = expandHome(dir);
  let files: LogFile[];
  try {
    files = logFiles(abs);
  } catch {
    throw new Error(`Log directory not found: ${abs}. Run the status method for a setup hint.`);
  }
  if (!files.length) {
    ctx.logger.info("No log files in {dir}", { dir: abs });
    return { dataHandles: [] };
  }
  const now = new Date();
  const oldest = new Date(Math.min(...files.map((f) => f.born.getTime())));
  const weeks = pickWeeks(oldest, now).sort();
  if (!weeks.length) {
    ctx.logger.info("No missing weeks");
    return { dataHandles: [] };
  }
  // Logs are append-only: a file last written before the earliest week cannot hold its calls.
  const from = weekBounds(weeks[0]).start;
  const paths = files.filter((f) => f.modified >= from).map((f) => f.path);
  const dataHandles = [];
  for (const s of build(paths, weeks, oldest, now)) dataHandles.push(await ctx.writeResource("weekly", `weekly-${s.week}`, s));
  ctx.logger.info("Wrote {n} weekly snapshots", { n: dataHandles.length });
  return { dataHandles };
}

/** Shared status: is the log directory configured, and which models have rates. */
export async function statusFlow(ctx: Ctx, dir: string, pricedModels: string[]) {
  const abs = expandHome(dir);
  let files: LogFile[] = [];
  try {
    files = logFiles(abs);
  } catch {
    // missing directory: reported as unconfigured below
  }
  const data = {
    configured: files.length > 0,
    dir: abs,
    files: files.length,
    oldest: files.length ? new Date(Math.min(...files.map((f) => f.born.getTime()))).toISOString() : null,
    pricedModels: [...pricedModels].sort(),
    hint: files.length ? null : `No .jsonl logs in ${abs}. Set this model's globalArguments to the tool's log directory.`,
  };
  return { dataHandles: [await ctx.writeResource("status", "status", data)] };
}
```

```ts
import type { Tool, WeeklySnapshot } from "./scan.ts";

export type Event = { date: string; label: string };

const BASELINE = { label: "2026-09-21 – 2026-10-09", from: "2026-09-21", to: "2026-10-08", days: 18 };
const CLAUDE_BASELINE = { inputPerDay: 192_000_000, peakContext: 965_000, subagentOpusShare: 0.81 };

/** Codex numbers for the Claude Code baseline dates. shortcut: peaks use whole weeks W39–W41 (W41 runs past 10-09). */
function codexBaseline(snaps: WeeklySnapshot[]) {
  const weeks = snaps.filter((s) => s.tool === "codex" && s.summary && s.start >= BASELINE.from && s.start <= BASELINE.to);
  if (!weeks.length) return null;
  const days = weeks.flatMap((s) => s.summary!.perDay).filter((d) => d.date >= BASELINE.from && d.date <= BASELINE.to);
  return {
    inputPerDay: Math.round(days.reduce((n, d) => n + d.tokens.input + d.tokens.cacheRead + d.tokens.cacheWrite, 0) / BASELINE.days),
    peakContext: Math.max(...weeks.map((s) => s.summary!.context.peak)),
    weeklyRateLimitPeakPct: Math.max(...weeks.map((s) => s.rateLimits?.weeklyPeakPct ?? 0)),
  };
}

/** The public contract. Reads only `summary`, `costCheck`, and `rateLimits` from snapshots; `private` never leaves. */
export function buildSummary(snaps: WeeklySnapshot[], events: Event[]) {
  const get = (week: string, tool: Tool) => snaps.find((s) => s.week === week && s.tool === tool);
  const weeks = [...new Set(snaps.map((s) => s.week))].sort().reverse(); // newest first; publish.sh reads weeks[0]
  return {
    schemaVersion: 1,
    // From snapshot times, not the clock: a run with no new snapshot writes an identical file.
    generatedAt: snaps.reduce((m, s) => (s.scannedAt > m ? s.scannedAt : m), ""),
    costBasis: "api-list-price-estimate",
    baseline: { label: BASELINE.label, claudeCode: CLAUDE_BASELINE, codex: codexBaseline(snaps) },
    events,
    weeks: weeks.map((week) => {
      const cc = get(week, "claudeCode"), cx = get(week, "codex");
      return {
        week,
        start: (cc ?? cx)!.start,
        status: [cc, cx].some((s) => s && !s.complete) ? "incomplete" : "complete",
        claudeCode: cc?.summary ? { ...cc.summary, costCheck: cc.costCheck } : null,
        codex: cx?.summary ? { ...cx.summary, rateLimits: cx.rateLimits } : null,
      };
    }),
  };
}

const fmt = (n: number) => (n >= 1e9 ? `${(n / 1e9).toFixed(2)}B` : n >= 1e6 ? `${(n / 1e6).toFixed(1)}M` : String(n));
const usd = (n: number | null) => (n === null ? "n/a" : `$${n.toFixed(2)}`);

/** Private detail for `swamp report get`. Contains project names: never publish. */
export function renderMarkdown(snaps: WeeklySnapshot[]): string {
  const out = ["# local-ai-usage (private)", ""];
  const sorted = [...snaps].sort((a, b) => b.week.localeCompare(a.week) || a.tool.localeCompare(b.tool));
  for (const s of sorted) {
    out.push(`## ${s.week} ${s.tool}${s.complete ? "" : " (incomplete)"}`, "");
    if (!s.summary) {
      out.push("No data.", "");
      continue;
    }
    const t = s.summary.tokens;
    out.push(`Calls ${s.summary.calls}, sessions ${s.summary.sessions}, input ${fmt(t.input + t.cacheRead + t.cacheWrite)}, output ${fmt(t.output)}, cost ${usd(s.summary.costUSD)}.`);
    if (s.costCheck && Math.abs(s.costCheck.deltaPct) > 2) {
      out.push(`**Price drift:** estimate differs from Claude Code's cost by ${s.costCheck.deltaPct}% over ${s.costCheck.sessions} sessions. Check prices.yaml.`);
    }
    if (s.private.unpricedModels.length) out.push(`**Unpriced models:** ${s.private.unpricedModels.join(", ")}. Add rates to prices.yaml.`);
    if (s.private.skippedLines) out.push(`Skipped lines: ${s.private.skippedLines}.`);
    out.push("", "| Project | Calls | Input | Output | Cost |", "|---|---|---|---|---|");
    for (const [p, v] of Object.entries(s.private.projects).sort((a, b) => b[1].input - a[1].input).slice(0, 10)) {
      out.push(`| ${p} | ${v.calls} | ${fmt(v.input)} | ${fmt(v.output)} | ${usd(v.costUSD)} |`);
    }
    const sub = Object.entries(s.private.subagentModelsByProject);
    if (sub.length) {
      out.push("", "Subagent calls by project and model:");
      for (const [p, m] of sub) out.push(`- ${p}: ${Object.entries(m).map(([k, v]) => `${k} ${v}`).join(", ")}`);
    }
    out.push("");
  }
  return out.join("\n");
}
```

```ts
    eventsFile: z.string().default("events.yaml"),
  }),
  resources: {
    summary: {
      description: "Public summary and private markdown",
      schema: z.looseObject({ public: z.unknown(), markdown: z.string() }),
      lifetime: "infinite",
      garbageCollection: 10,
    },
  },
  methods: {
    build: {
      description: "Write public/summary.json and the private markdown from the latest snapshot of every week",
      arguments: z.object({}),
      execute: async (_args: Record<string, never>, ctx: Ctx) => {
        const snaps: WeeklySnapshot[] = [];
        for (const name of ctx.globalArgs.sources as string[]) {
          const rows = await ctx.queryData(`modelName == "${name}" && specName == "weekly"`, "content");
          snaps.push(...rows.map((r) => (typeof r === "string" ? JSON.parse(r) : r) as WeeklySnapshot));
        }
        const events = Events.parse(parse(Deno.readTextFileSync(`${ctx.repoDir}/${ctx.globalArgs.eventsFile}`)) ?? []);
        const pub = buildSummary(snaps, events);
        const out = `${ctx.repoDir}/${ctx.globalArgs.outFile}`;
        Deno.mkdirSync(out.slice(0, out.lastIndexOf("/")), { recursive: true });
        Deno.writeTextFileSync(out, JSON.stringify(pub, null, 1) + "\n");
        ctx.logger.info("Wrote {weeks} weeks to {out}", { weeks: pub.weeks.length, out });
        return { dataHandles: [await ctx.writeResource("summary", "summary", { public: pub, markdown: renderMarkdown(snaps) })] };
      },
    },
  },
};
```
